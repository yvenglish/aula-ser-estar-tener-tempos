# YV Español — Ser, estar y tener

Projeto estático para GitHub Pages. A página trabalha os verbos **ser**, **estar** e **tener** no presente, pretérito indefinido e futuro simples, com vocabulário da mesa, áudio, leitura e exercícios interativos.

## Publicação

Envie `index.html`, `styles.css`, `script.js` e a pasta `assets` para a raiz do repositório e ative o GitHub Pages.
